Installed `@mastra/ai-sdk` converts the native `start` chunk payload and resolves its ID using native step-start. An isolated public SDK adapter check with only resumed tool-result/step/text/finish chunks produced no `start` at all, despite an explicit synthetic factory messageId (exit 0; no agent/provider execution). Thus `onMessageId` is called for an actual native UI start, not simply for construction of an observer.

It retains the full replay, then clears only its own native topic between owned-pointer read and subscription and requires 204. It separately masks committed Memory and requires an open non-204 view, not fabricated success. It also checks the split synthetic credential and all forty notes against owner, reader and saved Memory, with one admission/provider fixture call.

HTTP 204 is emitted only when the native replay is empty and that positive proof holds (or there is no native run to observe).
