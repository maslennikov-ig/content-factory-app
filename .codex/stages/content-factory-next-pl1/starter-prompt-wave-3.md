## Ловушки этого репозитория

- **Beads откатывает закрытия.** Не закрывай задачи, пока работают агенты.
  Сначала весь код, потом одной партией `bd close`, сразу `bd dolt push`, потом
  поимённо сверить через `bd show`. Вывод самой `bd close` рапортует успех и до
  отката.
- **`tsc -p apps/backend/tsconfig.build.json` не покрывает `libraries/`.**
  Полная проверка — `apps/backend/tsconfig.json`; в ней есть две
  унаследованные ошибки (`text-spots.ts`, `voice.service.ts:803`) из коммита
  `4511dd9c`, они не твои.
- **Клиент Prisma в этих репозиториях типизирован `Record<string, any>`.**
  Неправильный `where` не поймает ни компилятор, ни поддельная база — только
  рантайм. Поддельная база одна: `tests/helpers/voice-memory-prisma.cjs`,
  копий заводить нельзя (одна уже была и молча расходилась).
- **Полный прогон Jest ломает стенд фронтенда**: каждая страница отвечает 500,
  пока не удалить `apps/frontend/.next` и не перезапустить сервер.
- **Правки в `libraries/` не подхватываются `nest start --watch`** даже после
  `touch main.ts`: снеси `apps/backend/dist` и `tsconfig.tsbuildinfo`.
- `tests/public-funnel-runtime-proof.test.cjs` каждый раз переписывает
  свидетельство шестого этапа, поэтому `git status` показывает его грязным.
