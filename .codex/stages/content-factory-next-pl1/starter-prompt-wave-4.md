## Решение владельца, которое старше всех чисел

25.08.2026, дословно:

> Нельзя загонять модель в жёсткие рамки. Важно, чтобы был просто аватар,
> которым она представляется. Действую как он, она действует как аватар.

Из этого следует: блок голоса — **человек и его тексты**, а не перечень
указаний о манере. Всякое средство, которое добавляет в промпт правило, обязано
сначала доказать своё место числом, а не правдоподобием. Ограничения
(`guardrails`) — исключение: запрещённые темы не манера, а то, что пространству
позволено печатать.

Измерения к этому вели дважды, и оба раза вывод не был сделан:

- описательная половина блока (`describe` — точка зрения, регистр, черты, ритм,
  лексикон, политики) зарабатывает **ноль по всем четырём меркам**, держа при
  этом рекорд по доле шкал в коридоре (94,9 %);
- измеренные направления (`directions`, написаны в тот же день) **перелетают до
  117–134 %** закрытого разрыва — генерация ложится ближе к центру автора, чем
  его собственные отложенные посты. Правило, выполненное равномерно, сжимает
  человека к его среднему; живой автор вокруг своего среднего разбросан.

**Доля закрытого разрыва выше 100 % — это перелёт, а не успех.** Проверку на
карикатуру, которой требует приёмка `pl1.8`, теперь можно ставить числом.

## Где мы остановились

**Голос работает, и это измерено.** На шестнадцати парах без материала полный
голос закрывает **23,1 %** разрыва по правилу продукта, интервал 0,025…0,358
мимо нуля — самое устойчивое утверждение эпика.

**С материалом текст впервые читается как автор.** Эмодзи 88 % при его 92 %,
цифры 100 % при его 46 %; mStyleDistance 54,5 %, LUAR 21,1 %, оба интервала
мимо нуля, ни одного перелёта. Материал и голос работают на разных признаках:
цифры даёт материал даже без голоса, эмодзи — только голос.

**Чего всё ещё нет:** ссылок (0 % при его 33 %), длина 1432 против его 859.

## Открытый вопрос, который надо решить до платного прогона

**Отбор примеров пересаливает хвостом.** Плотность эмодзи в его корпусе — от 0
до 24,7 на тысячу при медиане 5,6, а три поста, доходящие до промпта, несут
13,7 / 3,0 / 17,2. «Максимум разнообразия внутри представительной половины»
систематически берёт хвосты.

Пока это три строки из девятнадцати — цена мала. **В аватаре это три строки из
четырёх, и хвост становится единственным учителем.** Два вопроса, оба открыты:

1. не отдавать ли в промпт самые **представительные** вместо самых разных,
   когда цитаты — весь стилевой сигнал;
2. не охватывает ли корпус владельца две разные манеры, из которых одна
   (старая, промо-регистр с эмодзи в каждой строке) уже не его.

Второй вопрос — владельца. Первый можно проверить бесплатно: поменять порядок
и посмотреть, что попадёт в цитаты.

## Следующий платный прогон

Когда вопрос с примерами решён:

```sh
export PATH="$HOME/.nvm/versions/node/v22.23.2/bin:$PATH"
docker start cf-dev-postgres
node scripts/evidence/voice-eval.cjs generate --corpus owner --with-material \
  --variants none,legacy,product,avatar --run owner-<дата>
node scripts/evidence/voice-eval.cjs measure --run owner-<дата> --cut 823
node scripts/evidence/voice-eval.cjs second  --run owner-<дата> --model mstyledistance
node scripts/evidence/voice-eval.cjs second  --run owner-<дата> --model luar
```

**32 генерации, 64 вызова.** Прогон платный: спроси разрешение прямо перед ним,
назвав это число. `measure` и `second` бесплатны и модель не зовут.

Вопрос прогона: бьёт ли аватар без единого правила то, что отгружается сейчас.
Если бьёт — `avatar` становится продуктовым блоком, и описательная половина
удаляется. Если нет — решение владельца всё равно в силе, но тогда надо понять,
что именно из удалённого держало число.

**Риск, который прогон покажет:** в аватаре нет строки про длину, и посты могут
стать длиннее. Демонстрация вместо инструкции — это порядок из §1.5 свода, но
цитаты сейчас 657–697 знаков при его медиане 859, то есть учат чуть короче.

## Что ещё найдено и не починено

- **С материалом контент повторяет хук** в половине генераций (4 из 8, без
  материала 0 из 8). Съедает десятую часть длины, читается как заикание. На
  сравнение вариантов не влияет — бьёт по всем одинаково.
- **Отказ по цитатам убивает оплаченную генерацию без второй попытки**
  (`CONTENT_CONTEXT_CITATIONS_INVALID`, один раз из восьми). Соседний путь
  `runAssist` повторяет один раз, этот — ни разу. В продукте это потерянный
  черновик у человека, приложившего источники.
- **Подрезка длины меряет не то:** сравнивает с диапазоном автора **только
  контент**, без хука, хотя 859 знаков измерены по целым постам. И ни разу не
  срабатывала — её потолок 1570, а контент выходит 1055–1392.

## Ловушки этого репозитория

- **Beads откатывает закрытия.** Не закрывай задачи, пока работают агенты.
  Сначала весь код, потом одной партией `bd close`, сразу `bd dolt push`, потом
  поимённо сверить через `bd show`.
- **`.codex/handoff.md` не длиннее 200 строк целиком** — это проверяет
  `run_process_verification.sh`, и файл сейчас ровно на пределе.
- **Полный прогон Jest ломает стенд фронтенда**: каждая страница отвечает 500,
  пока не удалить `apps/frontend/.next` и не перезапустить сервер.
- **Правки в `libraries/` не подхватываются `nest start --watch`**: снеси
  `apps/backend/dist` и `tsconfig.tsbuildinfo`.
- **Клиент Prisma типизирован `Record<string, any>`** — неправильный `where` не
  поймает ни компилятор, ни поддельная база. Поддельная база одна:
  `tests/helpers/voice-memory-prisma.cjs`, копий заводить нельзя.
- **Новое поле в содержимом профиля обязано попасть в список известных полей
  валидатора тем же коммитом**, иначе каждая активация с ним отвергается. Так
  портрет два месяца нельзя было включить вообще.
- `tests/public-funnel-runtime-proof.test.cjs` каждый раз переписывает
  свидетельство шестого этапа, поэтому `git status` показывает его грязным.
- Прогоны стенда лежат локально: `generations.json` в репозиторий не попадает
  (`.gitignore`), а норма и подставные — производная статистика, не текст.
