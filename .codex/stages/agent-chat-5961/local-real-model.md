## Runtime defects repaired locally

1. Replayed observers could remain streaming when a slow real provider reached
   a durable question, locking all answer controls. `AgentConversation` now
   reconciles the exact current owner's pending gate after native suspension
   events, including the short checkpoint-commit race. Bounded reads at
   0/100/500/1500/5000ms cancel on new events/unmount/turn/thread/Stop. Once the
   gate is confirmed it detaches only the SDK reader, never sends server Stop
   or replays an accepted answer. An unchanged in-flight answer gate cannot
   prematurely detach its own request.
2. A later question of the same tool could outlive a warm Session's suspension
   mirror. `streamNativeSession` now rebuilds only the exact addressed input
   entry from public `agent.listSuspendedRuns` before acknowledging the answer.
   Run/thread/resource/call must match; approval entries are not accepted as
   human input. No SDK private API or shared node_modules file was patched.
