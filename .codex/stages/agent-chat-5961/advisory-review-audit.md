## Findings and fixes

| Finding | Resulting behavior |
| --- | --- |
| Final review discarded an already generated post for missing scope, unsupported claims, copied wording or excess length. Even reviewer failure discarded the post. | Keep the exact draft and report `passed`, `partial` or `unavailable` honestly. Free copy/length findings survive unavailable semantic review. |
| A negative final review bought an unsolicited rewrite and another review. | One advisory semantic review; revisions require a new person request. The repair prompt and loop are removed. |
| Foreign-copy detection bought an earlier second draft, independently of the final loop. | Free literal findings, no automatic rewrite. Existing source fingerprints and own/foreign provenance distinction remain. |
| Missing/invented generated citation ids bought a complete replacement generation and could then fail the task. | Keep text, retain only ids belonging to admitted sources, and report missing/invalid bindings. Never invent a replacement source. Final review cannot erase this finding. |
| Conductor instructions and `assessmentRequired` demanded another editorial comparison after the domain review, with another full core copied into the tool result. | Report the saved draft and advisory; no additional check/rewrite to clear findings. Remove duplicate core/goal from the saved-text result; bounded exact text remains available. |
| Snapshot-wide insufficiency/unavailable review vetoed independently selected usable facts and exact retained passages. The tool description contradicted the existing partial-draft flow. | Run the existing per-selection source/quote checks, retain original assessment/gaps, and allow a supported partial draft. Carry the reader's explicit `scopeStatus` so a person-owned clarification still waits for an answer. |

identity, explicit human selection, publication consent, actual provider/DB

draft is distinct from an empty/malformed generation or a failed persistence.

failure and is bypassed for piece-core adaptation; it was not rewritten during
this bounded chat audit. No production/model routing or provider SDK changed.

## Preservation and limits

During implementation the local stand received a separate new user run, so
global record counts/usage legitimately increased. Initial records and chat
messages/metadata are checked by identity and content rather than requiring a
frozen global count. Current pending question/response receipts are retained
before the identity-checked backend refresh. Preservation receipts record the
final comparison; no answer, Stop, model request or retry is submitted by us.

This changes future generation behavior. The historical failed owner run is
not relabeled, replayed against a paid provider, or silently saved as a new
post. Real production-model editorial acceptance remains unverified; previous
unsupported-claim/date findings are still factual-quality evidence, now advice
instead of a draft-save gate. Semantic advice is retained in native chat, not
added to a new database column. It describes the generation-time text, and
later edits do not automatically buy another review.
