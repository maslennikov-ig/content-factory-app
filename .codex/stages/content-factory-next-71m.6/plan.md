# План `content-factory-next-71m.6`

1. Сверить устаревшие числа в описании Beads с текущими ограничениями compose
   и отдельными heap-cap трёх Node-процессов.
2. Пересчитать безопасный запас по принятому локальному профилю, не выдавая
   отложенную загрузку `googleapis` за неподтверждённую экономию контейнера.
3. Зафиксировать обратимое решение в production compose и защитить устойчивый
   контракт focused-тестом.
4. Выполнить одну root-owned release-приёмку, обновить Beads и создать ровно
   один коммит с указанием эскалации Луна → Терра.

Не входит: запуск контейнеров, доступ к серверу, развёртывание, измерение
production RSS, изменение состава сервисов и настройка памяти PostgreSQL,
Redis или Temporal без новых нагрузочных данных.
