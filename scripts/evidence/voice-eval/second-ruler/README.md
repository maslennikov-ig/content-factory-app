# Вторая мерка: LUAR и mStyleDistance

Инструмент замера, а не зависимость продукта. Живёт здесь, в `libraries/` не
попадает никогда, веса моделей в репозиторий не кладутся, среда — тоже.

## Зачем

Своя мерка стенда — символьные 5-граммы на обрезке 800 знаков. Оба ответа
исследования ставят её у нижней границы надёжности стилометрии, и числа стенда с
этим согласны: шум между двумя одинаковыми вариантами 0,028 при разрыве 0,051.
Пока вторая, независимо обученная мерка не посмотрела на те же тексты, «голос
ничего не делает» и «наша мерка этого не видит» — одно и то же утверждение.

## Установка

```sh
uv venv --python 3.12 scripts/evidence/voice-eval/second-ruler/.venv
uv pip install --python scripts/evidence/voice-eval/second-ruler/.venv/bin/python \
  torch --index-url https://download.pytorch.org/whl/cpu
uv pip install --python scripts/evidence/voice-eval/second-ruler/.venv/bin/python \
  transformers einops
```

Python 3.12 назван явно: по умолчанию на этой машине 3.14, под неё колёс torch
может не быть. `einops` нужен модельному коду LUAR и сам он его не тянет.

## Запуск

```sh
export PATH="$HOME/.nvm/versions/node/v22.23.2/bin:$PATH"
node scripts/evidence/voice-eval.cjs second --run <прогон>[,<прогон>…] \
  --cut 800 --model luar
node scripts/evidence/voice-eval.cjs second --run <прогон> --model mstyledistance
```

Ни одного вызова платной модели: веса скачиваются один раз в `weights/` и
считаются на процессоре. 273 текста — около минуты.

Отчёт ложится рядом с прогоном: `second-<модель>-cut<N>.{json,txt}`.

## Что считается

Слепок автора для этой мерки — среднее направление векторов **обучающей**
половины корпуса. Разбиение берётся то же, что у первой мерки, — анализатор
делит по хешу содержимого, — иначе расхождение двух мерок было бы о том, какие
посты каждая из них видела, а не о самих мерках.

Расстояние — косинусное до этого направления. Дальше всё как у первой мерки:
парные разности по темам, бутстрап с ресемплом тем, доля закрытого разрыва
(`paired.cjs`).

## Лицензии, проверено по карточкам моделей 25.08.2026

| Модель | Лицензия | Что это |
| --- | --- | --- |
| `rrivera1849/LUAR-MUD` | Apache-2.0 | контрастное представление авторства, обучено на миллионе авторов |
| `StyleDistance/mstyledistance` | MIT | многоязычное стилевое представление, девять языков включая русский |

Обе лучше по правам, чем утверждала любая из двух моделей исследования.
Проверено запросом к API Hugging Face, а не пересказом.

**LUAR требует `trust_remote_code`** — то есть исполнения чужого Python. Это
включено здесь явно и осознанно: инструмент замера на машине разработчика.
Рядом с продуктом такого нет и быть не должно.

## Граница, которую нашли числа: LUAR читает первые ~464 знака русского

Токенизатор LUAR английский, и кириллица дробится в нём вчетверо мельче: 800
знаков русского дают **886 токенов** при пределе модели в 512. То есть на
русском LUAR видит примерно **464 первых знака** текста, а не 800, и обрезка
стенда 800 против 823 не меняет её числа ни в одном разряде — модель обрезала
раньше.

mStyleDistance устроен иначе: 800 знаков — это 199 токенов, предел 512 покрывает
около 2085 знаков русского. Обрезка стенда для неё работает как задумано.

Практический вывод: сравнивать эти две мерки между собой можно только помня, что
они читают разные куски одного текста. И это же — цена языка уровня C по §3.3
спецификации, названная числом: у LUAR на русском вдвое меньше входа, чем на
английском.

## Если среда не поднимается

Задача не превращается в проект по установке torch. Запасной бесплатный канал —
расстояние по служебным словам (`functionWordDistance`, уже написан в
`voiceprint.ts`), и причина отката записывается рядом с числами.

25.08.2026 среда поднялась с первого раза, откат не понадобился.
