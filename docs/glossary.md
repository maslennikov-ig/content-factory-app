# Глоссарий

**Статус:** `current + target`

| Термин | Значение в этом проекте |
| --- | --- |
| Content Factory | Новый продукт, развиваемый на основе форка Postiz; временное имя Content Factory Next осталось только в исторических материалах |
| Postiz | Текущая исполняемая основа: редактор, календарь, каналы и публикация |
| Донор | Прежний `/home/me/code/content-factory`, используемый как источник требований до лицензионного решения |
| Organization | Корень изоляции данных одного клиента/пространства, tenant |
| Tenant | Изолированная область данных; в текущей модели соответствует Organization |
| Integration | Подключенный аккаунт/канал социальной платформы |
| Provider | Реализация платформенного OAuth, validation и публикации |
| Post | Строка публикации; цепочка может состоять из нескольких Post |
| Group | Идентификатор, объединяющий Post одной пользовательской операции |
| Materialization | Преобразование одобренного варианта Content Factory в существующие Post/Media/Tags |
| Workflow | Долговременная детерминированная последовательность Temporal |
| Activity | Операция Temporal с I/O или побочным эффектом |
| Task queue | Очередь Temporal, связывающая вызов с подходящим worker/provider |
| Source | Целевая сущность происхождения материала, не равная Media или URL в тексте |
| Evidence | Проверяемое утверждение/фрагмент, связанный с источником |
| Brief | Задание на материал: цель, тезис, аудитория, формат и доказательства |
| Variant | Одна редактируемая версия материала, созданная человеком или генерацией |
| Review | Структурированная проверка фактов, стиля, риска или политики |
| Approval | Явное решение, разрешающее следующий переход, в частности публикацию |
| Current-state | Поведение, уже подтвержденное кодом текущего репозитория |
| Target-state | Желаемая архитектура или функция, еще не обязательно реализованная |
| ADR | Запись принятого долговечного архитектурного решения |
| Beads | Единственный трекер задач и статусов проекта |
| Graphify | Локальный навигационный граф кода; не источник продуктовой истины |
| Public-safe | Не содержит secrets, private client data, live IDs/URLs и иных закрытых материалов |
