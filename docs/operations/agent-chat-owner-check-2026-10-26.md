# Что проверить в обновлённом чате

Откройте [ИИ-помощника](https://factory.aidevteam.ru/agents). Для первого
прохода достаточно одного нового задания и уже существующего чата.
Проверяйте черновик; публиковать пост для этой проверки не требуется.

1. **Обычное задание.** Например: «Собери обновления OpenAI за 19–25 октября
   2026 года и подготовь один пост для моего Telegram-канала. Сохрани основные
   изменения и ссылки, ничего не публикуй». Встроенные инструкции должны
   загрузиться сами. Просьбы разрешить загрузку инструкции быть не должно.
2. **Вопросы.** Если требуется ваш выбор, вопрос и разные варианты появляются
   прямо в чате. Выберите вариант или напишите свой ответ. «Решите за меня»
   доступно для редакторских решений, но не подменяет согласие на публикацию.
   После последнего ответа исходное задание должно продолжиться само.
3. **Результат.** Должен появиться сохранённый черновик с кнопкой открытия.
   Замечания к фактам, полноте, длине или совпадениям с источниками находятся
   в свёрнутом блоке «Замечания к черновику». Они не отменяют сохранение.
   Если проверка недоступна, это указано отдельно; текст не объявляется
   проверенным. Автоматической переписи ради снятия замечаний быть не должно.
4. **Перезагрузка.** Перезагрузите страницу во время вопроса и после сохранения.
   Вопрос, уже принятые ответы, черновик и замечания должны остаться. Не нужно
   повторять ранее принятый ответ или заново давать исходное задание.
5. **Остановка.** В отдельном задании нажмите «Остановить», затем перезагрузите
   страницу. Статус должен оставаться остановленным, без бесконечного
   «Работаем». Уже сохранённые результаты должны оставаться доступными.
   Продолжение запускайте только тогда, когда действительно хотите продолжить.

На главном экране больше нет постоянных надписей про отсутствие лимита ключа
и перечня вложений. Поддерживаемые файлы можно посмотреть через подсказку
рядом с кнопкой вложения.

Для быстрой проверки без новой генерации откройте существующий чат,
сохранённый черновик и подсказку вложений. Новые задания используют настроенные
API моделей и поиска с обычным учётом расходов пространства.

Отдельно прочитайте сам пост: отвечают ли факты источникам, сохранены ли даты,
оговорки и нужные темы. Сохранённый черновик и успешная техническая проверка
не означают, что текст уже прошёл вашу редакторскую приёмку.

Если что-то пошло не так, достаточно ссылки на чат, вашего действия и
ожидаемого результата. Историческая ошибка старого запуска остаётся в истории;
обновление не превращает её задним числом в успешный запуск.
