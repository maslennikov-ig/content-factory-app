## Область работы

Три задачи, один каталог, поэтому один поток.

### 1db — перевод экранов

По экрану за раз, не одним заходом. Большая часть точек применения лежит в
`apps/frontend/src/components/launches/**`, `new-launch/**` и `agents/**`.
Порядок выбирает исполнитель, но каждый экран — отдельный коммит с внятным
сообщением, чтобы правку можно было откатить поштучно.

Критерий: ни один примитив `ui/*` не остаётся без потребителя, либо для
оставшегося записана причина.

### 0h7 — ChannelMark

Примитив создан по образцу знака: две буквы в рамке 32px, radius 4, рамка
`border-control`, 13px/600 моноширинным, основной канал отмечается рамкой и
текстом `signature`.

Существенное ограничение: карточка **не должна вытеснять реальную картинку
аккаунта** там, где она есть. Это запасной вариант и метка провайдера, а не
замена аватара.

### 8ad — предпросмотр поста в модальном окне

`calendar.tsx:1016` делает `window.open('/p/' + post.id + '?share=true',
'_blank')`, а соседняя кнопка статистики открывает `modal.openModal`. Две кнопки
в одном ряду действий ведут себя по-разному, и предпросмотр уводит оператора из
календаря.

Ограничение: страницу `/p/[id]` удалять нельзя. Это публичная ссылка для
клиента, она ходит в `/public/posts/:id`, и уже разосланные ссылки обязаны
продолжать работать. Меняется только точка входа из календаря.

Решение владельца продукта: кнопка копирования публичной ссылки остаётся внутри
модалки, отдельная вкладка не нужна.

Приёмка задачи целиком: клик по иконке предпросмотра открывает модальное окно с
тем же содержимым, что и страница `/p/[id]`; внутри модалки работает копирование
публичной ссылки; прямой адрес `/p/[id]` по-прежнему открывается и остаётся
публичным; разметка поста не продублирована, а вынесена в общий компонент; без
iframe; модалка закрывается по Escape и по клику вне, фокус возвращается на
кнопку.

## Правила, которые валят сборку, а не ревью

`docs/design/component-authoring-rules.md` — читать до первой правки интерфейса.
Стражи: `tests/design.guard.test.cjs` (hex-литералы в JSX, `text-white`,
`customColor*`, sans-гарнитура на моноширинных токенах, с двусторонним реестром
долга), `tests/design.contrast.test.cjs` (47 пар, обе темы),
`tests/foundation.test.cjs`.

Девять типографических токенов доступны классами `cf-*`, плагин объявлен в
`apps/frontend/tailwind.config.cjs`.

## Чего делать нельзя

- Менять поведение экрана заодно с внешним видом. Замена компонента и правка
  логики — разные коммиты.
- Трогать `libraries/nestjs-libraries/src/openai/**` и экран настроек AI:
  параллельный поток владеет ими.
- Добавлять jsdom-харнесс, менять `jest.config.cjs` и `package.json` ради
  тестов на React. Их сейчас нет намеренно; если проверка невозможна
  поведенчески, это записывается как ограничение, а не обходится.
- Вводить новые зависимости и новые цвета. Только токены `cf`.
