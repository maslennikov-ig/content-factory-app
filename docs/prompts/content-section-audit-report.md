## Что осталось

1. **Коммит** правок аудита — за владельцем. Около 54 файлов, все проверены.
2. **Живой проход** на стенде: бриф → факт → копилот. Ни один экран в этой волне
   не открывался в браузере; всё доказано только тестами и типами.
3. **`fkft`.** Выпуск 02.09, применение схемы на боевой, остановка `send_email` v1
   и `push` в `origin/main` были исключены разделом «Полномочия» без отдельного
   слова владельца по каждому пункту; записи о таком слове нет ни в handoff, ни в
   runbook, ни в Beads. Это вопрос владельцу, не тебе. Если разрешение было, его
   надо записать в `production-deploy.md` по образцу прошлых выпусков.
4. **`lh5s`:** экран, где человек видит результат поиска и жмёт «принять» —
   по карте это бриф. Дверь подтверждения и кнопка на витрине уже есть.
5. **Открытое, без изменений:** `rrs9` (обучение описывает только контур
   Postiz), `4zef` (макет письма нарисован, письмо не переоформлено), `odb8.4`
   (поиск по словам не начат), четыре P3 выше.
6. **Вопрос владельцу, не решать за него:** ворота брифа пропускают утверждение
   с любой ссылкой, единый контекст — нет. Планка контекста теперь достижима, но
   бриф на голых ссылках из поиска по-прежнему даст черновик без единой цитаты.
