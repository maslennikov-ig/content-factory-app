## Representation and compatibility

Introduce an immutable v10 producer and a distinct cache identity. Keep all
older producer/compiler modules and v5/v4/v1 validation bodies byte-exact.
The new compiler composes the trusted v9 compiler and candidate qualification;
it does not repair old output or relax any old grounding condition.

Present entities select one numeric proof from the complete joint catalogue
of every legacy-valid unique query span and source with a containing unique
source anchor. Each proof binds exact query endpoints and its source. A proof
cannot combine an independently selected name with an unrelated source.
`claim_candidate` still asks the unchanged v9 qualification to establish
support after date filtering; `contextual_mention` stays context. Absence and
unknown retain the original unique query range and bounded absence rules.
The provider schema separates these branches, so a present entity cannot
omit its source proof. Generic phrases remain available in the catalogue but
are not thereby named entities or supported facts.

Enumerate every query-part endpoint pair accepted by the original resolver,
including whitespace and punctuation. Do not trim, whitelist names, drop
source anchors, cap proof counts by truncation, or infer a different name.
Lossless interval encoding may pack consecutive last endpoints for each
fixed source and first endpoint. Expansion must equal the full enumeration;
nonconsecutive ranges form separate runs. A dense numeric proof derives only
its exact query range/source. Source/query array positions can replace
redundant printed indices; all original literals, anchors and date-local
indices remain. Final encoding requires measured complete-envelope proof.

Each claim's dates are exactly five nullable slots in the fixed original
role order `[effective_from, effective_until, announced, target, as_of]`.
Each nonnull value is the original `{via, ref}` pair. Decode each nonnull
slot once into its corresponding v9 date role. Uniqueness is structural,
rather than deduplication. Fixed positions save 236 schema bytes compared
with a five-key object, allowing complete catalogues within the same caps.
No original valid date set is lost. `via` still selects a reference in this
claim, and the date-local reference must belong to that cited source. With
no date catalogue all five slots must be null.

The prompt explicitly requires every clause of a claim to be supported inside
that claim's selected spans. Details elsewhere in the same source are not
proof for that span. Split claims when two references cannot support every
clause. Preserve exact names, prices, units, bundles, conflicts and gaps;
publication time is not validity and retrospective sources remain allowed.
Structural proof does not establish meaning: actual root semantic acceptance
of fresh live results remains mandatory.
