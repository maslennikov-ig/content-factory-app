# Исследовательские отчёты

Внешние deep-research отчёты и внутренние аудиты, на которые опираются решения. Отчёт — это
основание, а не решение: что из него принято, записано в ADR, в спецификации `docs/product/` или
в задаче Beads. Отчёты не переписываются задним числом, даже когда продукт от них ушёл.

## Соглашение об именовании

`<предмет>-<исход-или-вывод>-<ГГГГ-ММ-ДД>.md` — строчными буквами, через дефис, латиницей.

- **Предмет** — что исследовали: `web-search-backend`, `image-editor`, `writer-voice`.
- **Исход** — вывод отчёта, если у него есть рекомендация: `tavily-primary`,
  `openrouter-parallel-primary`. Два отчёта по одному предмету с разными выводами тем и
  различаются. Если отчёт ничего не рекомендует, вместо исхода стоит его тема:
  `style-transfer`, `selection`, `donor-audit`.
- **Дата** — день, на который проверялись источники, а не день, когда файл лёг в репозиторий.
  Отчёт стареет вместе с источниками, и дата в имени — самое дешёвое предупреждение об этом.

Имя, выданное инструментом выгрузки (`compass_artifact_wf-…_text_markdown.md`,
`deep-research-report (61).md`), не сохраняется: по нему нельзя понять ни предмет, ни вывод, ни
возраст, и это уже стоило времени дважды. Пробелов и скобок в имени нет — они ломают команды,
которые ходят по путям без кавычек.

Файл переименовывается вместе с реестром `HISTORICAL_OPERATOR_ALLOWLIST` в
`tests/cloud-saas-contract.test.cjs`: сверка идёт по точной строке пути, поэтому переименование
без правки реестра валит тест дважды — новым путём и осиротевшим ключом.

Шесть отчётов о голосе бренда лежат **парами**: три запроса, каждый прогнан двумя разными
моделями. Это не удвоение объёма, а способ проверки, и имя модели в файле стоит затем, чтобы
расхождение можно было перечитать. Модель определена по формату выгрузки, а не по заявлению
внутри документа. Читать надо со свода: он делит всё на подтверждённое дважды, расходящееся,
непроверенное и лицензионно закрытое.

Два отчёта об авторском сходстве — такая же пара: один запрос, две модели, оба от 2026-08-27.
Они лежали до 31.08.2026 неучтёнными, под именами выгрузки, в подпапке `brand-voice/` рядом с
шестью побайтовыми копиями отчётов из таблицы выше. Копии удалены, эти два переименованы по
соглашению. Пока они лежали вне учёта, `tests/cloud-saas-contract.test.cjs` краснел на седьмом
файле той же кучи — дубле `writer-voice-style-transfer-2026-08-22.md`, — то есть страж видел
обещания оператора в документе, которого реестр не знал. Это и есть цена сырого имени.

Два отчёта о поисковом бэкенде противоречат друг другу намеренно — это второе мнение по одному
вопросу, а не устаревшая версия. Владелец выбрал Tavily основным; действующий контракт реализации
записан в [`../prompts/search-provider-port-spec.md`](../prompts/search-provider-port-spec.md).

Два файла без даты в имени — `image-editor-selection.md` и
`content-intelligence-donor-audit.md` — оставлены как есть намеренно. Соглашение действует для
новых отчётов; переименование ради единообразия стоит правки реестра в
`tests/cloud-saas-contract.test.cjs` и ссылок в ADR, а по их именам предмет и так понятен. Даты
этих двух стоят в таблице выше и в шапке самих файлов.
