# Видео V1: решения по четырём внешним отчётам

Дата сверки: **22 октября 2026**. Эпик: `content-factory-next-zlq6` / [HONEY-5940](https://linear.app/elwork/issue/HONEY-5940).
Это результат исследования и спецификация для разработки. Реальные генерации, качество речи, расход аккаунта и готовность к публичному запуску ещё не проверены.

## Принятое решение

**Higgsfield — основной API генеративных клипов. HeyGen — API ведущего, произносящего подготовленный сценарий. Runway — резервный кандидат, без третьей обязательной интеграции в V1.**

Пользователь работает в Content Factory: выбирает заготовку, формат и язык, получает редактируемый промпт/сценарий, видит параметры и оценку расхода, запускает генерацию и получает видео в медиатеке. Вся аудиовизуальная генерация выполняется провайдером. Собственный монтаж, таймлайн, склейка сцен, рендер и отдельная цепочка озвучки не нужны.

Higgsfield выбран из-за общего API нескольких моделей, документированных оценки цены и защиты от повторного платного задания. Это инженерный выбор для первого подключения, **не доказательство превосходства качества или надёжности над Runway**. Скидка не закладывается в постоянный тариф продукта. [Запросы Higgsfield](https://docs.higgsfield.ai/docs/concepts/requests), [оценка и биллинг](https://docs.higgsfield.ai/docs/concepts/billing-and-retention), [повтор одного запроса](https://docs.higgsfield.ai/docs/concepts/idempotency).

Для ведущего минимальный обязательный путь — **HeyGen `POST /v3/videos`** с нашим сценарием, выбранным голосом и разрешённым аватаром. Провайдер делает речь, синхронизацию губ и MP4. Это лучше соответствует контролю исходных фактов, чем обязательная передача авторства сценария внешнему агенту. Точное произношение всё равно проверяется на результате. [Контракт создания видео](https://developers.heygen.com/reference/create-video).

**HeyGen Video Agent** (`POST /v3/video-agents`, `mode=generate`) и **Higgsfield Cinema Studio 4.0** подтверждены как API. Они остаются дополнительными возможностями для составных роликов; их подключение и редактирование не блокируют V1. Cinema Studio создаёт новое видео, а не предоставляет универсальный API монтажа. [Video Agent](https://developers.heygen.com/reference/create-video-agent-session), [Cinema Studio](https://docs.higgsfield.ai/docs/models/cinema-studio-4/generate).

## Стартовый каталог API

Настройки ниже — проверенный публичный контракт на дату сверки. Наличие доступа конкретного аккаунта и качество конкретного языка остаются отдельной проверкой. Полный каталог в интерфейс не выгружаем: начинаем с трёх явных вариантов клипов и одного режима ведущего.

| Пользовательский выбор | Точный маршрут | Ограничения |
|---|---|---|
| Экономнее: Wan 3.0 | Higgsfield `/alibaba/wan-3.0/text-to-video` и `/image-to-video` | 2–30 с, 480p/720p/1080p; явное соотношение сторон; параметр native audio не означает гарантированный язык речи |
| Кандидат баланса: Kling 3.0 Standard | Higgsfield `/kling-video/v3.0/std/text-to-video` и `/image-to-video` | 3–15 с; настройки конкретного endpoint. Не смешивать с Pro/4K |
| Расширенный вариант: Kling 3.0 Pro | Higgsfield `/kling-video/v3.0/pro/text-to-video` и `/image-to-video` | 3–15 с; повышенная цена сама по себе не делает его победителем качества |
| AI-ведущий | HeyGen `POST /v3/videos`; результат `GET /v3/videos/{video_id}` | Подготовленный сценарий, совместимые locale/voice/avatar/engine, MP4. В V1 предлагаем сценарии примерно 15/30/60 с как целевую длину, не гарантию точного хронометража API |

Источники: [Wan text](https://docs.higgsfield.ai/docs/models/wan-3/text-to-video), [Wan image](https://docs.higgsfield.ai/docs/models/wan-3/image-to-video), [Kling routes](https://docs.higgsfield.ai/docs/models/kling-3), [Standard](https://docs.higgsfield.ai/docs/models/kling-3/standard-text-to-video), [Pro](https://docs.higgsfield.ai/docs/models/kling-3/pro-text-to-video), [голоса HeyGen](https://developers.heygen.com/reference/list-voices), [результат HeyGen](https://developers.heygen.com/reference/get-video).

В интерфейсе доступны 9:16 и 16:9, а 1:1 — только для подтверждённой комбинации. Не переводить произвольный запрос на неподдерживаемый формат скрытым кропом. Для клипа без речи выбранная локаль определяет смысловую адаптацию; наличие текстового prompt не обещает локализованные надписи или озвучку.

## Подготовка промптов и ограничения

Из заготовки берём авторский замысел, аудиторию, один ключевой смысл, источники и факты. Факты делим на обязательные к произнесению/показу и контекст, которому нельзя противоречить. Не нужно пытаться поместить весь Telegram-пост в десять секунд.

Компактный бриф хранит визуальное намерение, стиль, собственные референсы, целевой язык, длительность и формат. Для клипа готовится описание результата и движения; для ведущего — сценарий на выбранном языке. Политика точного сценария не допускает молчаливого переписывания после подтверждения. Числа, даты, единицы, отрицания и имена проверяются отдельно от стиля.

Языки интерфейса, источника, технического промпта, речи и субтитров разделены. Не создаём глобальный список «только ru/en». Отсутствие подтверждённой комбинации языка и голоса показываем до оплаты; автозамены языка нет. Указание языка в промпте генеративного клипа — пожелание, пока нет доказательства нужного качества.

Показываем редактируемый итоговый промпт/сценарий и параметры до запуска. Пользователь может попросить новую версию; правка готового видео в V1 означает подготовку новой оплачиваемой попытки. Автономные бесконечные перегенерации и скрытая замена провайдера исключены. Нет обязательного отдельного экрана для каждого промежуточного этапа.

## Надёжность и продуктовые границы

Сохраняем идентичность запроса до отправки. Для Higgsfield повтор после сетевой неопределённости возможен с тем же `Idempotency-Key` и неизменным запросом; `422` не повод выдать новый ключ. Для HeyGen эквивалентная гарантия не подтверждена: потерянный ответ требует выяснения исхода, а не нового платного submit. Политика повтора принадлежит адаптеру и имеет общий ограниченный бюджет. [Higgsfield idempotency](https://docs.higgsfield.ai/docs/concepts/idempotency).

При перезагрузке продолжаем наблюдение за тем же заданием. Загрузка файла повторяется отдельно от генерации. Файл переносим в своё хранилище до истечения ссылки; у Higgsfield документировано минимум семь дней, но продукт не должен зависеть от этого срока. Отмена Higgsfield действует только до начала обработки. [Billing/retention](https://docs.higgsfield.ai/docs/concepts/billing-and-retention).

Повторно используем текущие режимы владения ключом `included` / `workspace_key`, шифрование, права пространства и учёт операций; включённый режим видео появляется лишь при явной настройке оператором. Старый лимит количества видео не является денежным потолком. Новый кошелёк или платёжный тариф не входит в эпик. Условия коммерческого использования конкретного API-аккаунта проверяются перед внешним запуском; отчёт не доказывает право перепродажи и не требует sales-контракта по предположению.

Если позже включается HeyGen Video Agent, отдельно фиксируем `visibility=private` и `incognito_mode=true`, чтобы общий аккаунт провайдера не добавлял память чужой сессии. Это не заменяет tenant-проверки нашей платформы и не означает отсутствие хранения у провайдера. [Session contract](https://developers.heygen.com/reference/create-video-agent-session).

## Приёмка исследования и дальнейшая работа

Исследовательская задача `.1` выполнена: четыре материала сопоставлены, ключевые конфликты проверены по первичным страницам, API-портфель выбран, неизвестные отделены от фактов. [План реализации](../superpowers/plans/2026-10-22-video-generation.md) задаёт шесть оставшихся задач, их зависимости и доказательства приёмки. Сам эпик остаётся открытым до реализации и проверки обоих потоков.

Первые проверки реализации выполняются на fake API и готовом fixture-видео. Позднее предлагается ограниченный пилот: пять брифов × два способа подготовки × две попытки = **20 генераций**. Три клиповых случая покрывают Wan, Kling Standard и Pro; два случая ведущего — разные поддержанные языки. Точный бюджет рассчитывается по выбранным параметрам перед отдельным разрешением на расходы. Исходный и подготовленный промпты сравниваются на одинаковой модели, настройках и референсах. Этот пилот не доказывает универсальный рейтинг всех провайдеров.

Два аналитических потока `gpt-6-luna/max` полностью прочитали пары отчётов; root принял их как анализ утверждений и самостоятельно проверил перечисленные API-контракты и цены. Их записки сохранены в частном архиве; запись принятия — этот раздел. Изменений кода/общих файлов агентами не было, удалять их артефакты не требуется. Проверка планирования: локальные ссылки (217 файлов), соответствие семи задачам и diff — PASS; без вызовов генерации и подключения ключей.
