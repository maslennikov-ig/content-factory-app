Для меня исландский эксперимент — сильный довод: сокращение рабочего времени может сохранять производительность, а где-то — повышать её.

С 2015 по 2019 год более 2500 сотрудников из 100 организаций перешли с 40-часовой недели на 35- или 36-часовую без снижения зарплаты.

Что изменилось в работе:
• задачи стали быстрее передавать друг другу;
• отказались от лишних встреч;
• короче стали перерывы.
