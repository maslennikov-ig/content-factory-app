# Экраны раздела «Контент» — выгрузка дизайн-проекта

**Что это.** Дословная копия файлов проекта Claude Design
`1e1241d6-c61e-4a1f-9e7a-b891c1e9ab58`. Шесть файлов выгружены 2026-08-22 задачей
`content-factory-next-36r.12`, седьмой — `Avatars.dc.html` — 2026-08-25 в волне три эпика
`content-factory-next-pl1`, когда владелец заказал двенадцатый экран. Выгружено, чтобы
дальнейшая работа над экранами раздела читала локальные файлы, а не ходила в MCP: инструмент
`DesignSync` доступен только корневому сеансу, у субагентов его нет, и повторная выгрузка каждый
раз стоит контекста.

Выгружено выборочно, а не целиком: проект с тех пор оброс файлами публичной главной, знака и
платформенных карточек — они принадлежат другим задачам, и копия здесь описывает раздел
«Контент».

**Правка запрещена.** Это референс, а не исходник продукта. HTML не собирается, не импортируется
кодом и приведению к стилю репозитория не подлежит: единственная ценность копии — сверяемость с
оригиналом. Если дизайн-проект изменится, папка переимпортируется целиком.

## Что из `CHANGES.md` уже влито, а что нет

Читать этот файл как список предстоящей работы **нельзя** — большая его часть уже сделана.

- **Пункты 1–7 влиты эпиком `content-factory-next-5g8`.** Оливковые нейтрали, жёлто-зелёный
  акцент, светлая навигация, потемневшая охра, осветлённый кармин, два моноширинных токена и
  значения `backdrop`/`overlay-shadow` живут в продукте с 2026-08-13. Применять их второй раз
  нечего. Их же историческая копия лежит в [`../changes.md`](../changes.md) — снимок на момент
  того переноса, семь пунктов без восьмого.
- **Новый только пункт 8** — токен `display-num`. Он реализован этой же задачей: класс
  `cf-display-num` в `apps/frontend/tailwind.config.cjs`, правило в `DESIGN.md` и
  `../design-system.md`, дополнение к [ADR-0008](../../../adr/0008-dark-first-desert-lab-visual-system.md),
  проверка в `tests/design.typography.test.cjs`.

Две расхождения оригинала с продуктом, которые при чтении сбивают и потому названы здесь:

1. **Раздел «Чего не делали» в `CHANGES.md` всё ещё говорит «те же девять типографических
   токенов»**, хотя пункт 8 добавляет десятый. Это несогласованность внутри исходного файла;
   копия оставлена дословной. Верное число — десять продуктовых токенов.
2. **`CHANGES.md` и `../design-system.md` приписывают `display-num` фичу `tnum`.** В продукте её
   нет и не будет: вшитая JetBrains Mono не поставляет таблицу `tnum`, а её цифры и так
   моноширинные — табличность даёт сама гарнитура. Реализация ставит `font-feature-settings:
   'zero'`, как у двух других моноширинных токенов. Это осознанное расхождение, а не пропуск.

## Как посмотреть

`.dc.html` требуют рантайма Claude Design. Локально достаточно открыть файл в браузере из этой же
папки — `support.js` лежит рядом и подхватывается относительной ссылкой. Шрифты тянутся из Google
Fonts, поэтому без сети экраны отрисуются системной гарнитурой; для сверки композиции и состояний
этого хватает, для сверки типографики — нет.
