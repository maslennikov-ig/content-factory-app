# Контрольные пары контраста

Источник: проект дизайн-системы Content Factory в Claude Design, файл `Contrast.dc.html`.
47 пар, по которым проверяются обе темы. Это вход для `tests/design.contrast.test.cjs` — тест
парсит таблицу ниже, поэтому её формат менять нельзя: пять колонок, значения `Цвет` и `Фон` —
имена ролей без префикса `--cf-`, `Порог` — `4.5`, `3` или `инф.`.

Порог 4.5 — обычный текст и placeholder. Порог 3 — крупный текст, границы управляемых элементов,
маркеры выбора и кольцо фокуса. `инф.` — пара смысла не несёт: разделители, рамки панелей и
соотношение плоскостей приводятся справочно и тест не валят.

Кольцо фокуса на акцентной кнопке измеряется к подложке, потому что между кольцом и заливкой лежит
отступ 2px цвета `surface`.

## Формула

Та же, что в WCAG 2.x и в исходном расчёте дизайн-проекта:

```
канал  = значение / 255
линейн = канал <= 0.03928 ? канал / 12.92 : ((канал + 0.055) / 1.055) ^ 2.4
L      = 0.2126 * R + 0.7152 * G + 0.0722 * B
ratio  = (max(L1, L2) + 0.05) / (min(L1, L2) + 0.05)
```
