# Артефакты дизайн-системы «desert-lab»

Что это: результат работы Claude Design по брифу
[`docs/prompts/design-system-desert-lab-brief.md`](../../prompts/design-system-desert-lab-brief.md).
Проект дизайн-системы — `1e1241d6-c61e-4a1f-9e7a-b891c1e9ab58` на claude.ai/design.

Копии лежат здесь, а не только по ссылке, потому что ссылка не читается из CI, не проверяется
тестом и может стать недоступной.

| Файл | Что внутри | Кто использует |
|---|---|---|
| [`design-system.md`](design-system.md) | Исходный `DESIGN.md` дизайн-проекта: токены, типографика, правила | Основа для корневого `DESIGN.md` |
| [`tokens.css`](tokens.css) | Значения `--cf-*` для `:root` и `.dark` | Этап токенов, `apps/frontend/src/app/colors.scss` |
| [`contrast-pairs.md`](contrast-pairs.md) | 47 контрольных пар и формула | `tests/design.contrast.test.cjs` |
| [`changes.md`](changes.md) | Семь расхождений с прежней системой и что каждое ломает | Оценка риска, ADR, ревью |
| [`mark.md`](mark.md) | Измерения знака `Cf 98` по размерам | Компонент знака и иконки |
| [`content/`](content/) | Одиннадцать экранов раздела «Контент» в девяти состояниях, `1024/768/390`, EN | Эпик `content-factory-next-36r` |

Файлы `.dc.html` дизайн-проекта долгое время сюда не переносились: они требуют рантайма Claude
Design (`support.js`) и являются спецификацией-превью, а не кодом продукта. Для раздела «Контент»
это решение отменено — [`content/`](content/) держит их вместе с рантаймом. Причина не в том, что
превью стало кодом, а в том, что `DesignSync` доступен только корневому сеансу: без локальной
копии каждый интерфейсный ребёнок эпика заново выгружал бы триста килобайт разметки. Правила
обращения те же, что ниже: копия дословная, правке не подлежит, при изменении проекта
переимпортируется целиком.

`changes.md` — снимок на 2026-08-13, семь пунктов. Восьмой (`display-num`) появился позже и лежит
в [`content/CHANGES.md`](content/CHANGES.md) вместе с остальными семью; исторический снимок
намеренно оставлен как был.

Порядок применения и критерии приёмки — в
[`../desert-lab-implementation-spec.md`](../desert-lab-implementation-spec.md).

## Правила обращения с этими файлами

Копии считаются снимком решения на момент импорта. Если дизайн-проект изменится, файлы
переимпортируются целиком, а не правятся вручную: расхождение между копией и продуктом должно
разрешаться в пользу нового импорта, иначе тест контраста начнёт проверять несуществующую систему.

Значения отсюда переносятся дословно. Подгонять цвет «на глаз» под текущий интерфейс нельзя:
каждое значение в `tokens.css` уже проверено расчётом против 47 пар.
