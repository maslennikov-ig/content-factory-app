# Макеты «Календарь без рейки» 08.09.2026

Референс, не исходник продукта: артборды Claude Design для второго этапа после
раздела «Каналы» (эпик `content-factory-next-tu3k.14`). Холст:
`https://claude.ai/code/artifact/34828750-6edb-47d8-97e4-7cccbc395aac`.
Приняты владельцем 08.09.2026 («мне нравится»). Заказ исполнителю —
`docs/prompts/astra-calendar-only-2026-09-08.md`, задачи `content-factory-next-tu3k.14.27`–`.30`.

Зачем: с отдельным разделом «Каналы» рейка в календаре теряет смысл (выбор
заказчика уже в панели фильтров, перетаскивание канала на сетку ничего не
делает). Плюс в календаре открывал пустой «Чистый лист», хотя тексты рождаются в
разделе контента. Предложение: календарь отвечает «когда», раздел «Контент» —
«что».

Что сверялось с продуктом: карточка поста в клетке — с холста
`../calendar/` (полоска этапа, заголовок, метки каналов, время); панель
фильтров `launches/filters.tsx` (Сегодня, период, День · Неделя · Месяц ·
Список, выбор заказчика); окно поста одно на продукт (`new-launch/manage.modal.tsx`,
дверь `shared/use-open-post.tsx`). Имена каналов и посты вымышленные.

| Файл | Экран | Что предложено |
| --- | --- | --- |
| `Main.dc.html` | `/launches`, неделя | Рейки нет, сетка на всю ширину; в панели «Все заказчики», «Все каналы», primary «+ Запланировать»; наведение на пустую клетку показывает «+ 15:00». Меню: «Контент» вместо «Заготовки» (шаг 3). |
| `PickerReady.dc.html` | выбор «Что публикуем» | Окно 600 px: дата из клетки, поиск, фильтр по каналу, список готовых адаптаций без даты (канал, заголовок, код заготовки, «готово дд.мм»); «Открыть в окне поста» primary; внизу тихий «Чистый лист» с подписью «пост без конвейера». |
| `PickerEmpty.dc.html` | выбор, готовых нет | Объяснение пути мысль → заготовка → адаптация, «В контент →»; «Чистый лист» остаётся. |
| `PostLink.dc.html` | пост и заготовка | Во всплывающем окне поста строка «из заготовки cnt-06 → открыть» — только у постов, рождённых адаптацией. |

Знаки площадок на макетах — настоящие файлы `apps/frontend/public/icons/platforms/*.png`,
переданные холсту при сборке (`--image`), в дерево не копируются. В продукте они
показываются через `PlatformBadge` (16 px в рамке 24 у аватара канала, в клетке
календаря и в строке выбора) и `PlatformCardLogo` (48 px в поле 56 на плитках
подключения); условия показа — `../platform-mark-display-rules.md`.

Правка этих файлов запрещена: следующая волна делает свой холст.
