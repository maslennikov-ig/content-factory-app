# Макеты волны по живому прогону 07.09.2026

Референс, не исходник продукта: артборды Claude Design, показанные владельцу
07.09.2026 и одобренные («в целом мне нравится») до правки кода. Холст:
`https://claude.ai/code/artifact/c569cf13-cf99-48a6-a1ef-f2f2640b7767`.
Эпик Beads `content-factory-next-m2eg`, находки — `.codex/stages/content-factory-next-fn33/evidence/walk-2026-09-07/notes.md`.

| Файл | Экран | Что решено |
| --- | --- | --- |
| `PiecePage.dc.html` | `/content/pieces/[id]` | Первым блоком «Уточнение» (пока есть вопросы), затем суть, сразу под ней «Куда адаптировать» с одной главной кнопкой; правая колонка узкая и справочная. Вопрос о фактах читается «На что это опирается?» (слово владельца). |
| `PiecesTable.dc.html` | `/content?tab=materials` | Настоящие колонки по площадкам, «Раскрыть строку» — кнопка-стрелка, раскрытие на месте; чип «ещё нет» пунктиром без квадрата; полоса «Заготовки \| Что уже написали» остаётся с подписью, зачем второй вид. |
| `ComposeFooter.dc.html` | окно поста, низ | Без галочек и без «Проверил»: два справочных блока «Что взято и откуда» и «Свои тексты по теме»; одна основная кнопка, «Опубликовать сейчас» — пункт меню за стрелкой, по клику. |
| `ChannelsRail.dc.html` | `/launches`, панель каналов | Оба состояния: все кнопки 40 высотой, radius 8, «+» отличается только заливкой; аватар 40 и «⋮» на одной оси; развёрнуто — «Пост» и «Заготовка» две равные кнопки. |

Каждый артборд несёт чип `dark` (переключатель темы): значения токенов —
из `../content/tokens.css`. Правка запрещена: следующая волна делает свой холст.
