Правила в дизайн-систему
  • Раскрытие — только общий компонент; новые ▸ и details страж не пропустит
  • Подпись раздела — компонент; заголовок внутри не крупнее подписи раздела
  • Тексты интерфейса — только в файлах копий; мёртвые ключи падают
  • Слово и тон состояния — из одного места (клетки состояния)
  • Всплывающие меню — через общий слой с тенью
  • Удаление — одной кнопкой со взведением
  • Высота касания 44 px — забота кнопки, не экрана
  • Кнопка при загрузке не меняет ширину
  • Одна вещь — одно имя из одного ключа
