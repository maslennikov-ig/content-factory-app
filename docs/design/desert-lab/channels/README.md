# Макеты раздела «Каналы» 08.09.2026

Референс, не исходник продукта: артборды Claude Design для нового раздела
`/channels` (шаг 2 пути «Конвейер в меню», эпик `content-factory-next-tu3k.14`).
Холст: `https://claude.ai/code/artifact/94559304-b77f-4d35-959c-4eccf4bb0888`.
Заказ исполнителю — `docs/prompts/astra-channels-section-2026-09-08.md`, задача
`content-factory-next-tu3k.14.26`.

Зачем: первая реализация `/channels` показывала рейку каналов из календаря,
растянутую на всю ширину; владелец её отклонил. Раздел должен отвечать на четыре
вопроса: какие каналы подключены и живы ли, как в каждый пишем (карточка), когда
выходим (расписание), что уже выходило.

**Решение владельца 08.09:** один список каналов в двух видах показа —
«Карточки» (по умолчанию) и «Таблица» — с переключателем, который запоминается в
браузере; фильтр состояния и поиск работают в обоих видах; клик по карточке или
строке открывает одну и ту же страницу канала. Вариант «список слева, карточка
справа» рассматривался и отклонён: с сеткой карточек он не совмещается.

Что сверялось с продуктом: боковое меню 248 px и строка 32 px
(`new-layout/sidebar.tsx`), шапка 56 px, отступ раздела 20 px, панели с радиусом 8,
кнопки 40/32, чипы 24, сегменты `ui/segmented.tsx`, токены `cf-*` из
`../content/tokens.css`; поля и слова карточки «Как пишем сюда» — из
`intake/intake.copy.ts` и `intake/writing-profile.card.tsx`; действия меню канала —
из `launches/menu/menu.tsx`; состояния — из `Integrations` (`disabled`,
`refreshNeeded`, `inBetweenSteps`, `writingProfileStored`). Имена каналов и посты
на макетах вымышленные.

| Файл | Экран | Что решено |
| --- | --- | --- |
| `Main.dc.html` | `/channels`, вид «Карточки» | Ряд управления: переключатель «Карточки · Таблица», фильтр состояния, поиск. Сетка по три, группы по заказчику заголовками; на карточке состояние, строка карточки письма или чип «карточка не заполнена», последний пост, число постов, слоты; «Как пишем» / «Заполнить карточку» / «Открыть». |
| `ChannelsTable.dc.html` | `/channels`, вид «Таблица» | Тот же ряд управления; колонки «Канал · Состояние · Как пишем · Расписание · Последний пост · ···»; клик по строке открывает страницу канала. |
| `ChannelPage.dc.html` | `/channels/<id>` | «← Все каналы»; шапка канала с действиями; четыре панели: «Как пишем сюда», «Расписание», «Что здесь выходило», «Подключение». |
| `ChannelPageEdit.dc.html` | правка карточки | «Изменить» переключает панель на сегменты на месте; «Сохранить» / «Отмена» / «Вернуть умолчания»; заметка до 500 знаков со счётчиком. Без модального окна. |
| `ChannelPageDefaults.dc.html` | канал без карточки | Жёлтая подсказка «карточка не заполнена: модель пишет по умолчаниям» с действием «Заполнить»; это не ошибка. |
| `ChannelsEmpty.dc.html` | пустое состояние | Объяснение, плитки площадок для подключения, подсказка про карточку. |
| `ChannelsMobile.dc.html` | до 720 px | Только список; страница канала с вкладками «Карточка · Расписание · Выходило · Подключение». |

Состояния канала одной точкой: зелёная «работает», жёлтая «нужно переподключить»,
серая «выключен», красная «подключение не закончено». Все действия старого меню
«···» сохраняются и разложены по панелям страницы; меню дублирует их.

Знаки площадок на макетах — настоящие файлы `apps/frontend/public/icons/platforms/*.png`,
переданные холсту при сборке (`--image`), в дерево не копируются. В продукте они
показываются через `PlatformBadge` (16 px в рамке 24 у аватара канала, в клетке
календаря и в строке выбора) и `PlatformCardLogo` (48 px в поле 56 на плитках
подключения); условия показа — `../platform-mark-display-rules.md`.

Правка этих файлов запрещена: следующая волна делает свой холст.
